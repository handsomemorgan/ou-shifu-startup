# 鸥师傅创业方法论

一套用于审视具体创业决策的中文 Skill。完整方法论及使用指引见 [SKILL.md](SKILL.md)。

它保留创业四步法、一句话检验、架构判断、生产杠杆与融资叙事，并补充 AI 时代的商业模式判断：

- 从信息差与认知差，转向稀缺供给、决策能力与授权执行。
- 检验平台的必要性，分析需求方 Agent、供给方 Agent 与交易基础设施的关系。
- 从经营记录系统，走向经营推演沙盘，再走向授权经营代理。
- 把定价、供需约束与经营目标联合建模，用真实结果验证价值。
- 区分生产杠杆与代理权，检验收费依据、分成归因和利益一致性。
- 以定制验证真实需求，抽象共性并验证可复制交付，复用成熟底座。
- 从低阻力切口进入工作流，靠结果和明确授权扩大代理范围。

## 使用

本仓库根目录即 Skill 目录，入口是 `SKILL.md`，标识为 `ou-shifu-startup`。将它作为 Skill 加载，或把文件作为方法论参考材料使用。

适合创业方向、MVP、产品标准化、商业模式、架构与融资判断；普通写作、代码、搜索和排版无需套用。

## 本次完善

新增内容从创业讨论中提炼，不保留具体行业案例。趋势判断按可验证假设处理；模拟数据、免费安装与一次定制成功，分别不能替代真实收益、付费验证与跨客户复制证明。

## 边界

这是判断框架，不替代真实调研、财务测算或专业法律与投资意见。使用时应区分已验证事实、合理推断和未来愿景。
